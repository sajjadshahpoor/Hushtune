YouTube, plus a browser that respects you.

Hushtune is an iPhone app for browsing and searching YouTube, and a general-purpose mobile browser with ad blocking, video downloads, and background audio — built entirely on standard iOS frameworks.

What's inside

Four features, each built on a real, documented iOS API — nothing hidden or hacked together.

▶

YouTube search & play

Search and browse trending videos via YouTube's official Data API, played through YouTube's own embeddable player with a custom Hushtune interface around it.

🛡

Ad & tracker blocking

A built-in browser blocks common ad and tracking domains using Apple's WKContentRuleList API — the same mechanism behind Safari content blockers — plus a pop-up blocker.

⭳

Video downloads

Auto-detects direct video file links on the page you're browsing, or accepts a pasted URL, and downloads them for offline playback in-app.

🔊

Background audio

A real AVAudioSession background-playback configuration keeps ordinary web media playing when you lock your screen or switch apps.

How to install

Hushtune isn't on the App Store, so getting it onto your iPhone takes one of these paths.

1
Get the source or a release

Clone the GitHub repo, or download a build from the Releases section below if one has been published.

2
Open it in Xcode on a Mac

Run xcodegen generate, open Hushtune.xcodeproj, and add your own YouTube Data API v3 key in Sources/Config.swift.

3
Install to your iPhone

Connect your iPhone and hit Run in Xcode to install it directly, or use a signed build via TestFlight / ad-hoc distribution once one is set up.
